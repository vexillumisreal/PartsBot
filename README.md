# 📱 PartsBot — Telegram-бот для управления каталогом, складом и заказами запчастей

[![Python 3.11+](https://img.shields.io/badge/python-3.11+-blue.svg)](https://www.python.org/downloads/)
[![Aiogram 3.x](https://img.shields.io/badge/aiogram-3.x-green.svg)](https://docs.aiogram.dev/)
[![SQLite](https://img.shields.io/badge/database-SQLite%20%2F%20aiosqlite-lightgrey.svg)](https://github.com/omnilib/aiosqlite)
[![License](https://img.shields.io/badge/license-MIT-purple.svg)](LICENSE)

**PartsBot** — профессиональный Telegram-бот для автоматизации розничной и оптовой торговли запчастями для смартфонов, планшетов и портативной техники. Включает многоуровневый каталог, корзину с оформлением заказов, складской учёт с фиксацией закупочной себестоимости, аналитику дефицита (Smart Procurement) и панель управления заказами.

---

## ✨ Основные возможности

### 🛍️ Каталог и Покупки (для клиентов)
* **4-уровневая структура навигации**:
  $$\text{Бренд (Apple, Samsung, Xiaomi...)} \longrightarrow \text{Модель (iPhone 13, A51...)} \longrightarrow \text{Категория запчасти (Дисплеи, АКБ...)} \longrightarrow \text{Конкретная деталь}$$
* **Умный поиск**: мгновенный текстовый поиск по фрагменту модели или наименования (например: `13 oled`, `redmi 9`, `A51`).
* **Двойные цены**:
  * **Розница** — базовая стоимость для частных покупателей.
  * **Опт** — скидка 20% для авторизованных сервисных центров и мастеров.
* **Карточки товаров**: фото/схема, статус наличия на складе, подробные характеристики и генерация QR-кода детали.
* **Корзина и оформление**:
  * Выбор способа получения (Самовывоз со склада в Казани / Курьер / СДЭК).
  * Выбор способа оплаты (При получении / СБП по QR / По счёту юрлица).
  * Ввод контактных данных и примечаний к заказу.

### 📦 Складской учёт (для кладовщиков и менеджеров)
* **📥 Оприходование товара**:
  * Быстрый поиск детали или выбор по цепочке *Бренд $\to$ Модель $\to$ Категория*.
  * Обязательный запрос **закупочной себестоимости** партии.
  * Автоматический пересчёт общей стоимости поставки `(Количество × Закупочная цена)`.
  * Сохранение себестоимости в базе и запись в историю `stock_history`.
* **📤 Списание и Корректировка**: списание брака, расхода в сервис с обязательным комментарием.
* **📋 Журнал движения**: полная история приходов и расходов с фиксацией сотрудника, даты, цен и поставщика.
* **🚨 Контроль неснижаемого остатка**: автоматические уведомления о дефиците с кнопкой моментального оприходования в 1 клик.

### ⚙️ Панель администратора и Менеджера
* **🛍️ Управление заказами клиентов**:
  * Интерактивный список с фильтрацией: *Все*, *⏳ Новые*, *📦 В обработке*, *🚚 Отправленные*, *✅ Выполненные*, *❌ Отмененные*.
  * Просмотр карточки заказа: контакты клиента, состав позиций, сумма, доставка.
  * Смена статуса заказа и статуса оплаты (*Оплачен* / *Не оплачен*).
  * Автоматическое списание остатков со склада при завершении заказа.
  * Push-уведомление клиенту в Telegram при смене статуса его заказа.
* **⏳ Прогноз закупок (Smart Procurement)**:
  * Анализ темпа продаж (30-дневный *burn rate*).
  * Расчёт оставшихся дней запаса для каждой позиции.
  * Автоматический расчет рекомендованного объёма дозаказа для покрытия потребностей склада.
* **📈 Аналитика и Экспорт**:
  * Выручка, средний чек, маржинальность, топ продаваемых товаров.
  * ABC-анализ номенклатуры склада.
  * Рейтинг ключевых клиентов (LTV).
  * Экспорт отчётов в CSV-формате.
* **👥 Управление доступом**:
  * Назначение ролей: Администратор, Менеджер склада, Менеджер продаж.
  * Одобрение/отклонение заявок от клиентов на получение оптового статуса.

## 🚀 Установка и быстрый старт

### 1. Системные требования
* Python **3.11** или выше.
* Операционная система: Windows / Linux / macOS.
* Установленный SQLite3 (входит в стандартную библиотеку Python).

### 2. Клонирование и виртуальное окружение
```bash
git clone https://github.com/your-username/PartsBot.git
cd PartsBot

# Создание виртуального окружения
python -m venv .venv

# Активация окружения:
# Windows (PowerShell):
.venv\Scripts\Activate.ps1
# Linux / macOS:
source .venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения
Создайте или отредактируйте файл `.env` в корне проекта:
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
ADMIN_ID=6139301544
ADMIN_IDS=6139301544,8556038901
```
* `BOT_TOKEN` — токен вашего бота, полученный у [@BotFather](https://t.me/BotFather).
* `ADMIN_ID` — основной Telegram ID главного администратора (узнать свой ID можно через [@userinfobot](https://t.me/userinfobot)).
* `ADMIN_IDS` — список через запятую всех ID, обладающих правами суперадминистратора.

### 5. Импорт номенклатуры из прайс-листа Excel
Если у вас есть файл `Цены Казань.xlsx`, запустите парсер номенклатуры:
```bash
python import_kazan_prices.py
```
> Скрипт автоматически разобьёт 770+ позиций по брендам, сериям моделей и типам запчастей (Дисплеи, Аккумуляторы, Крышки и т.д.), запишет розничную цену из колонки F и рассчитает оптовую цену со скидкой 20%.

### 6. Запуск бота
```bash
python bot.py
```
При запуске бот автоматически применит миграции базы данных, синхронизирует суперадминистраторов из `ADMIN_IDS` и начнёт приём сообщений.

## 🗄️ Схема базы данных

Таблицы создаются автоматически при первом старте бота (`db.init_db()`):

| Таблица | Назначение |
|---|---|
| `users` | Профиль пользователя Telegram, роль (`user`, `warehouse_manager`, `sales_manager`, `admin`), статус (`retail`, `wholesale`). |
| `parts` | Каталог запчастей: `category` (Бренд), `subcategory` (Модель), `part_type` (Тип детали), `retail_price`, `wholesale_price`, `cost_price`, остаток `quantity`, порог оповещения. |
| `stock_history` | Журнал складских движений: приход, расход, списание, фиксация закупочной цены партии, поставщика и сотрудника. |
| `orders` | Заказы покупателей: сумма, статус выполнения, статус оплаты, выбранная доставка и реквизиты. |
| `order_items` | Детализация состава заказов: привязка к `part_id`, зафиксированная цена и количество на момент покупки. |
| `wholesale_requests` | Заявки розничных покупателей на получение статуса оптового клиента (для СЦ и мастеров). |

## 💡 Технические особенности

1. **Защита от лимита 64 байт Telegram**: в каталоге и на складе все callback-кнопки используют детерминированные компактные ключи (`cbr_iph`, `cmd_iph_12`, `ctp_iph_12_disp`), что исключает сбои при длинных названиях моделей.
2. **Асинхронность**: полный переход на `aiosqlite` и `asyncio`, исключающий блокировку событийного цикла при высокой нагрузке.
3. **Безопасное редактирование сообщений**: предотвращение исключений `message is not modified` и дублирующих `callback.answer()`.
