# 🤖 PartsBot - Telegram бот для управления запчастями

Модерный Telegram-бот для управления каталогом запчастей с поддержкой оптовых и розничных цен, отслеживанием поступлений и администрирования.

## ✨ Основные функции

### 👥 Для пользователей
- 🛍️ **Просмотр каталога** - категоризированный каталог запчастей
- 💰 **Двойные цены** - розничные и оптовые цены в зависимости от статуса
- 📱 **Удобный интерфейс** - кнопки и меню вместо команд
- 📚 **7 категорий** - Дисплеи, Крышки, Аккумуляторы, Шлейфы iPhone/Android, Камеры, Динамики

### ⚙️ Для администраторов
- ➕ **Добавление запчастей** - полная информация о товаре
- 📥 **Приходование** - отслеживание поступлений с историей
- 📊 **Статистика** - быстрый обзор каталога
- 🔐 **Защита** - доступ только для администратора

## 🚀 Быстрый старт

### Требования
- Python 3.8+
- pip
- Токен Telegram бота

### Установка

1. **Клонируйте репозиторий**
```bash
cd PartsBot
```

2. **Создайте виртуальное окружение**
```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
# или
source .venv/bin/activate  # Linux/Mac
```

3. **Установите зависимости**
```bash
pip install aiogram
```

4. **Добавьте ваш токен бота**
Откройте `bot.py` и замените:
```python
BOT_TOKEN = "ВАШ_ТОКЕН_ЗДЕСЬ"
ADMIN_ID = ВАШ_TELEGRAM_ID
```

5. **Запустите бота**
```bash
python bot.py
```

## 💻 Использование

### Для обычных пользователей

1. **Запустите бота**: `/start`
2. **Просмотрите каталог**: Нажмите "📦 Каталог запчастей"
3. **Выберите категорию**: Нажимайте на нужную кнопку
4. **Добавьте в приходование**: "📥 Приходование" (если у вас есть права)

### Для администраторов

1. **Войдите в админ-панель**: Нажмите "⚙️ Админ-панель"
2. **Добавьте запчасть**: Выберите "➕ Добавить запчасть"
3. **Заполните информацию**:
   - Категория
   - Название
   - Поставщик
   - Себестоимость
   - Розничная цена
   - Оптовая цена
4. **Приходуйте запчасти**: "📥 Приходование" → Выберите запчасть → Количество → Поставщик
5. **Смотрите статистику**: "📊 Статистика" в админ-панели

## 🗄️ Структура базы данных

### Таблица: `users`
Хранит информацию о пользователях и их статусах.

```sql
CREATE TABLE users (
    user_id INTEGER PRIMARY KEY,
    status TEXT DEFAULT 'retail'  -- 'retail' или 'wholesale'
)
```

### Таблица: `parts`
Каталог всех запчастей.

```sql
CREATE TABLE parts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    category TEXT,
    name TEXT,
    supplier TEXT,
    cost_price REAL,
    retail_price REAL,
    wholesale_price REAL,
    quantity INTEGER DEFAULT 0,
    last_updated TIMESTAMP DEFAULT CURRENT_TIMESTAMP
)
```

### Таблица: `stock_history`
История всех поступлений.

```sql
CREATE TABLE stock_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    part_id INTEGER,
    quantity INTEGER,
    supplier TEXT,
    date TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    notes TEXT,
    FOREIGN KEY (part_id) REFERENCES parts(id)
)
```

## ⚠️ Возможные проблемы

### "Бот не отвечает"
- Проверьте токен
- Убедитесь что бот запущен: `python bot.py`
- Проверьте интернет-соединение

### "Ошибка при добавлении запчасти"
- Проверьте что вы администратор
- Убедитесь что вводите числа в числовые поля
- Перезагрузите бота

### "База данных не создается"
- Проверьте права на запись в папку
- Удалите `spare_parts.db` и перезагрузите бота

- ✅ Валидация числовых полей
- ✅ Защита от SQL-инъекций (parameterized queries)
- ✅ Отсутствие чувствительных данных в коде (используйте переменные окружения!)

### ⚠️ Важно!

Никогда не коммитьте ваш токен и ID в Git!

Используйте `.env` файл:
```python
# .env
BOT_TOKEN=your_token_here
ADMIN_ID=your_id_here
```

Загружайте из переменных окружения:
```python
import os
from dotenv import load_dotenv

load_dotenv()
BOT_TOKEN = os.getenv("BOT_TOKEN")
ADMIN_ID = int(os.getenv("ADMIN_ID"))
```
