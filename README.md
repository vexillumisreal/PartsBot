**PartsBot** — профессиональный сервис автоматизации торговли запчастями для мобильной техники, объединяющий **многофункционального Telegram-бота (aiogram 3.x)** и **современное веб-приложение Telegram Mini App (aiohttp + Glassmorphism UI)** с единым бэкендом, складским учётом и прозрачной обработкой заказов.

---

## 🌟 Ключевые компоненты платформы

### 1. 📱 Telegram Mini App (Web App)
* **Премиальный дизайн**: стеклянный интерфейс (Glassmorphism), плавная адаптивная верстка под тему Telegram (Dark/Light), поддержка Safe Area для iPhone.
* **3-уровневый иерархический каталог**:
  $$\text{Бренды} \longrightarrow \text{Модели} \longrightarrow \text{Чипсы типов деталей (Дисплеи, АКБ, Шлейфы...)} \longrightarrow \text{Список запчастей}$$
* **Мгновенная корзина и чекаут**:
  * Локальное сохранение состояния корзины в `localStorage`.
  * Выбор вариантов получения: Самовывоз (склад Казань), СДЭК, курьер по городу.
  * Выбор вариантов оплаты: при получении, перевод по СБП (с автоматическим QR-кодом), безналичный расчёт.
* **Тактильный отклик**: интеграция с `Telegram.WebApp.HapticFeedback` (виброотклик при добавлении в корзину, ошибках и оформлении).
* **Сквозные Telegram-уведомления**: сразу после оформления в Mini App клиент получает детализированный чек и реквизиты в чат бота, а сотрудники — интерактивную карточку управления заказом.

### 2. 🤖 Telegram-бот (aiogram 3.x)
* **Автодополнение команд**: зарегистрированные команды (`/start`, `/search`, `/cart`, `/orders`, `/profile`, `/help`, `/cancel`).
* **Умный поиск `/search <запрос>`**:
  * Полнотекстовый поиск по фрагментам названия, бренда и модели.
  * Встроенная пагинация с компактным хэшированием (CRC32) для строгого соблюдения 64-байтного лимита Telegram Callback Data.
* **Двухуровневая система цен**:
  * **Розница** — базовые цены для частных покупателей.
  * **Опт** — специальные цены для партнёров и сервисных центров.
* **Интерактивная корзина в боте**: возможность оформления как через интерфейс Telegram-чата, так и через Mini App.

### 3. 📦 Складской учёт и аналитика
* **Приходование**: пошаговый FSM-мастер добавления партий с фиксацией закупочной себестоимости и поставщика.
* **Списание и корректировка**: фиксация расхода запчастей и списания брака.
* **Контроль дефицита**: автоматические алерты при остатке ниже неснижаемого порога.
* **Прогноз закупок (Smart Procurement)**: расчёт темпа расхода (30-day burn rate) и рекомендации по дозаказу.
* **Финансовая аналитика**: валовая прибыль, маржинальность, ABC-анализ ассортимента, выгрузка в CSV.

## 🔌 REST API эндпоинты WebApp

Встроенный веб-сервер запускается параллельно с ботом на порту `8888` (или переопределяется через переменную окружения `PORT`):

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/brands` | Список брендов с количеством активных моделей и запчастей |
| `GET` | `/api/models?brand={brand}` | Список моделей указанного бренда |
| `GET` | `/api/parts?brand={brand}&model={model}` | Список запчастей конкретной модели |
| `GET` | `/api/catalog?q={query}&page={0}&limit={100}` | Глобальный поиск по номенклатуре |
| `GET` | `/api/user_status?user_id={id}` | Проверка ценового статуса (`retail` или `wholesale`) |
| `POST` | `/api/order` | Оформление заказа, списание со склада и рассылка уведомлений |

### Пример тела запроса `POST /api/order`:
```json
{
  "user_id": 6139301544,
  "user_name": "Иван Иванов",
  "contact": "+7 (999) 000-00-00",
  "delivery_method": "pickup",
  "delivery_address": "",
  "payment_method": "sbp",
  "notes": "Просьба проверить ревизию дисплея",
  "items": [
    { "id": 42, "quantity": 1 }
  ]
}
```

## 🚀 Установка и запуск

### Вариант 1: Локальный запуск

1. **Клонируйте репозиторий и создайте виртуальное окружение:**
   ```bash
   git clone https://github.com/your-username/PartsBot.git
   cd PartsBot
   python -m venv .venv

   # Windows
   .venv\Scripts\Activate.ps1
   # Linux / macOS
   source .venv/bin/activate
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Создайте файл `.env`:**
   ```env
   BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   ADMIN_ID=6139301544
   ADMIN_IDS=6139301544,8556038901
   WEBAPP_URL=https://your-domain.bothost.tech/index.html
   PORT=8888
   ```

4. **Запустите проект:**
   ```bash
   python bot.py
   ```

---

### Вариант 2: Облачный деплой (Bothost / Docker)

Проект полностью оптимизирован для контейнеризированного хостинга (например, [Bothost](https://bothost.ru/)):

В корне репозитория присутствует готовый `Dockerfile`:
```dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
EXPOSE 8888
CMD ["python", "bot.py"]
```

1. Подключите Git-репозиторий в панели управления хостинга.
2. Укажите переменные окружения (`BOT_TOKEN`, `ADMIN_ID`, `WEBAPP_URL`).
3. При сохранении контейнер автоматически собирается и поднимает бота вместе с сервером Mini App.

## 🔒 Безопасность и отказоустойчивость

* **Защита от SQL-инъекций**: все запросы выполняются строго с параметризацией через плейсхолдеры `?`.
* **Защита от XSS во фронтенде**: клиентская фильтрация и отрисовка используют функцию безопасного экранирования `escapeHtml()` и атрибуты данных `data-*` без прямой конкатенации строк в DOM.
* **Атомарная проверка остатков**: при создании заказа проверяется доступное количество каждого товара; при дефиците возвращается статус `409 Conflict` с указанием конкретной позиции.
* **Соблюдение лимитов Telegram**: поиск оснащён таблицей сопоставления по CRC32-хэшам, что гарантирует работу кнопок обратного вызова при любой длине поискового запроса.
