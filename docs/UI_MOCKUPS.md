## 💡 Дизайн-принципы

### Структура экрана

```
┌─ ЗАГОЛОВОК (emoji + жирный текст)
├─ РАЗДЕЛИТЕЛЬ (пустая строка)
├─ ОСНОВНОЙ КОНТЕНТ (форматированный)
├─ РАЗДЕЛИТЕЛЬ (пустая строка)
└─ ДЕЙСТВИЕ (кнопки или подсказка)
```

### Использование emoji

| Позиция | Использование | Цель |
|---------|--------------|------|
| Начало заголовка | 📦 📥 ⚙️ | Быстрое распознавание |
| Перед элементом | ✓ • ▪ | Структура списка |
| Перед значением | 📊 👤 📝 | Категоризация данных |
| Кнопка действия | ✅ ❌ 🔙 | Интуитивное понимание |

### Форматирование

```
**Жирный** → Заголовки
`Моноширинный` → Данные, числа
_Курсив_ → Подсказки, вторичная информация
Обычный → Основной текст
```

---

## 🎯 Адаптивность

### Для мобильных
- ✅ Максимум 2 кнопки в строку (удобно нажимать)
- ✅ Компактный текст (без лишних пробелов)
- ✅ Быстрые переходы (не более 3-4 кликов)

### Для планшетов/ПК
- ✅ Расширенное отображение
- ✅ Сетка кнопок сохраняется
- ✅ Удобное чтение текста

---

## 🎨 Цветовая схема (Текстовая)

```
Основной цвет → Жирный текст (**...**)
Акцент → Emoji в начале строки
Вторичный → Курсив (_..._)
Код/Число → Моноширинный шрифт (`...`)
Ошибка → ❌ Красный emoji (визуально)
Успех → ✅ Зеленый emoji (визуально)
Действие → Кнопки/инлайн-кнопки
```
