## 🚀 Процесс Приходования Запчастей {#приходование}

### Этапы приходования (FROM → TO)

```
START (Пользователь нажимает "📥 Приходование")
  ↓
[Выбор категории] ← CATEGORIES
  ├─ 📱 Дисплеи
  ├─ 🔲 Крышки
  ├─ 🔋 Аккумуляторы
  ├─ 📞 Шлейфы iPhone
  ├─ 🤖 Шлейфы Android
  ├─ 📷 Камеры
  └─ 🔊 Динамики
  ↓
[Выбор запчасти из категории]
  • Запчасть 1 (текущее кол-во: X шт)
  • Запчасть 2 (текущее кол-во: Y шт)
  ↓
[Ввод количества] ← Validation: целое число > 0
  ↓
[Ввод поставщика] ← Опционально
  ↓
[Выбор: Завершить или добавить примечание?]
  ├─ ✅ Завершить
  │   ↓
  │   [Обновление БД]
  │   • UPDATE parts SET quantity = quantity + N
  │   • INSERT INTO stock_history
  │   ↓
  │   [Подтверждение завершения]
  │   ✅ Приходование завершено!
  │   📦 Запчасть: {name}
  │   📊 Кол-во: +{quantity} шт
  │   ↓
  │   END
  │
  └─ 📝 Добавить примечание
      ↓
      [Ввод примечания]
      ↓
      [Возврат к выбору завершение/примечание]
      ↓
      (переход на "Завершить")
```

### Таблица данных для приходования

| Поле | Тип | Описание |
|------|-----|---------|
| `part_id` | INTEGER | ID запчасти из таблицы `parts` |
| `quantity` | INTEGER | Количество поступивших единиц |
| `supplier` | TEXT | Поставщик |
| `notes` | TEXT | Примечание об условиях поступления |
| `date` | TIMESTAMP | Дата/время приходования |

## 📚 Процесс Просмотра Каталога {#каталог}

```
START (Пользователь нажимает "📦 Каталог запчастей")
  ↓
[Загрузка категорий из БД]
  SELECT DISTINCT category FROM parts
  ↓
[Отображение категорий с emoji]
  📱 Дисплеи    | 🔲 Крышки
  🔋 Аккумуляторы | 📞 Шлейфы iPhone
  🤖 Шлейфы Android | 📷 Камеры
  🔊 Динамики
  ↓
[Выбор категории]
  ↓
[Загрузка запчастей из выбранной категории]
  SELECT * FROM parts WHERE category = ?
  ↓
[Определение цены на основе статуса пользователя]
  IF user_status = 'wholesale'
    → price = wholesale_price
  ELSE
    → price = retail_price
  ↓
[Отображение запчастей]
  📦 **Категория: {category}**
  
  ✓ Запчасть 1
     Цена: 500 руб. | Кол-во: 10 шт
  
  ✓ Запчасть 2
     Цена: 1200 руб. | Кол-во: 5 шт
  ↓
END
```

### Фильтрация по статусу

```
РОЗНИЦА (Retail) ─→ Показывать retail_price
           ↓
Пользователь переглядывает товар
           ↓
ОПТ (Wholesale) ─→ Показывать wholesale_price
```

## 🔄 Диаграммы Переходов Состояний {#диаграммы}

### StockInState (Приходование)

```
┌──────────────┐
│    START     │
└──────┬───────┘
       │ callback: stockin_{category}
       ↓
┌─────────────────────────┐
│  StockInState.quantity  │  ← Пользователь выбирает запчасть
└──────┬──────────────────┘
       │ message: целое число > 0
       ↓
┌─────────────────────────┐
│  StockInState.supplier  │  ← Введено кол-во
└──────┬──────────────────┘
       │ message: текст (опционально)
       ↓
┌─────────────────────────┐
│   StockInState.notes    │  ← Введен поставщик
└──────┬──────────────────┘
       │
       ├─ message: "✅ Завершить"
       │   ↓
       │   [UPDATE parts + INSERT stock_history]
       │   ↓
       │   END (State cleared)
       │
       └─ message: "📝 Добавить примечание"
           ↓
           [Ввод примечания]
           ↓
           [Возврат к выбору]
```

### PartState (Добавление запчасти)

```
┌──────────────┐
│    START     │
└──────┬───────┘
       │ callback: addcat_{category}
       ↓
┌──────────────────────┐
│  PartState.name      │ ← Категория выбрана
└──────┬───────────────┘
       │ message: текст
       ↓
┌──────────────────────┐
│  PartState.supplier  │ ← Имя введено
└──────┬───────────────┘
       │ message: текст
       ↓
┌──────────────────────┐
│ PartState.cost_price │ ← Поставщик введен
└──────┬───────────────┘
       │ message: float
       ↓
┌──────────────────────────┐
│ PartState.retail_price   │ ← Себестоимость введена
└──────┬───────────────────┘
       │ message: float
       ↓
┌──────────────────────────┐
│PartState.wholesale_price │ ← Розничная цена введена
└──────┬───────────────────┘
       │ message: float
       ↓
[INSERT INTO parts VALUES (...)]
       ↓
✅ ЗАВЕРШЕНО
END (State cleared)
```

## 🗄️ Структура Базы Данных

### Таблица: users

```sql
CREATE TABLE users (
    user_id INTEGER PRIMARY KEY,
    status TEXT DEFAULT 'retail'  -- 'retail' или 'wholesale'
)
```

### Таблица: parts

```sql
CREATE TABLE parts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    category TEXT,              -- Название категории
    name TEXT,                  -- Название запчасти
    supplier TEXT,              -- Поставщик
    cost_price REAL,            -- Себестоимость
    retail_price REAL,          -- Розничная цена
    wholesale_price REAL,       -- Оптовая цена
    quantity INTEGER DEFAULT 0, -- Текущее кол-во на складе
    last_updated TIMESTAMP      -- Время последнего обновления
)
```

### Таблица: stock_history

```sql
CREATE TABLE stock_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    part_id INTEGER,            -- Ссылка на запчасть
    quantity INTEGER,           -- Количество поступлений
    supplier TEXT,              -- Поставщик
    date TIMESTAMP,             -- Дата поступления
    notes TEXT,                 -- Примечания
    FOREIGN KEY (part_id) REFERENCES parts(id)
)
```

## 🛠️ Использование

### Запуск бота

```bash
python bot.py
```

### Начало работы

1. Напишите боту `/start`
2. Для админа напишите `/admin`
3. Сначала добавьте запчасти через админ-панель
4. Затем используйте приходование и каталог

### Быстрые команды

- `/start` - главное меню
- `/help` - справка
- `/admin` - админ-панель (только для админа)
