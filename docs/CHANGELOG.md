### 🛡️ Обработка ошибок

#### 1. Ошибки каталога
- ⚠️ Пустая категория → "В категории нет запчастей"
- ⚠️ Пустая подкатегория → "В подкатегории нет запчастей"
- ⚠️ Попытка приходовать товар из пустой категории → "Нельзя приходовать товар, которого нет в базе"

#### 2. Ошибки приходования
- ❌ Неправильное количество → "Пожалуйста, введите целое число!"
- ❌ Количество ≤ 0 → "Количество должно быть больше 0"
- ❌ Ошибка базы данных → "Ошибка при сохранении данных"

#### 3. Ошибки доступа
- ❌ Пользователь пытается приходовать → "У вас нет прав для приходования"
- ❌ Пользователь пытается в админ-панель → "У вас нет доступа к админ-панели"
- ❌ Пользователь пытается управлять ролями → "Только администратор может управлять ролями"

#### 4. Ошибки отчетов
- ⚠️ Нет финансовых данных → "Нет финансовых данных"
- ⚠️ Нет данных о поставщиках → "Нет данных о поставщиках"
- ⚠️ Нет движений товара → "Нет данных о движении товара"

#### 5. Другие ошибки
- 🔄 Ошибка получения подкатегорий → Fallback на прямой выбор запчастей
- 🔄 Ошибка получения запчастей → Пустой список с сообщением об ошибке
- 🔄 Ошибка БД → Console log + graceful message в UI

## 🚀 Как обновиться с v1.0 на v2.0

### Автоматическое обновление БД
- Новые таблицы создаются автоматически при запуске `bot.py`
- Старые таблицы `users` и `parts` сохраняются

### Миграция данных (опционально)
```sql
-- Добавить новые поля в parts (если нужно)
ALTER TABLE parts ADD COLUMN quantity INTEGER DEFAULT 0;
ALTER TABLE parts ADD COLUMN last_updated TIMESTAMP DEFAULT CURRENT_TIMESTAMP;
```

### Обновление кода
```bash
# Обновить bot.py - скопировать новый файл
# Обновить db.py - скопировать новый файл
# Установить зависимости
pip install -r requirements.txt
# Запустить
python bot.py
```
