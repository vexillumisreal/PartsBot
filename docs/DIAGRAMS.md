# 🎯 VISUAL FLOW DIAGRAMS - PARTSBOT

## 📊 Основная архитектура системы

```
┌──────────────────────────────────────────────────────────────┐
│                         TELEGRAM                              │
│                       (Пользователь)                          │
└────────────────┬─────────────────────────────────────────────┘
                 │
                 ▼
┌──────────────────────────────────────────────────────────────┐
│                  PARTSBOT (Python Bot)                        │
│         (bot.py - Async Dispatcher & Handlers)               │
│                                                               │
│  ┌───────────────┐  ┌──────────────┐  ┌────────────────┐   │
│  │   /start      │  │  /catalog    │  │   /admin       │   │
│  │   Menu Items  │  │  Categories  │  │   Admin Panel  │   │
│  └───────────────┘  └──────────────┘  └────────────────┘   │
│                                                               │
└────────────────┬─────────────────────────────────────────────┘
                 │
                 ▼
┌──────────────────────────────────────────────────────────────┐
│                   DATABASE LAYER (db.py)                     │
│                    (SQLite3)                                 │
│                                                               │
│  ┌──────────────┐  ┌──────────────┐  ┌────────────────┐   │
│  │    users     │  │    parts     │  │ stock_history  │   │
│  │              │  │              │  │                │   │
│  │ • user_id    │  │ • id         │  │ • id           │   │
│  │ • status     │  │ • category   │  │ • part_id      │   │
│  │              │  │ • name       │  │ • quantity     │   │
│  │ (2-3 записи) │  │ • supplier   │  │ • supplier     │   │
│  │              │  │ • cost_price │  │ • date         │   │
│  │              │  │ • quantity   │  │ • notes        │   │
│  │              │  │ (4-20 записи)│  │                │   │
│  └──────────────┘  └──────────────┘  │ (N записей)    │   │
│                                        └────────────────┘   │
│                                                               │
└──────────────────────────────────────────────────────────────┘
```

## 📥 Flow: Приходование запчастей (FROM → TO)

```
┌──────────────────────┐
│   Менеджер нажимает  │
│  📥 Приходование     │
└─────────┬────────────┘
          │
          ▼
   ┌────────────────────────┐
   │  STATE: None           │
   │  Выбор категории       │
   │                        │
   │  [📱 Дисплеи]          │
   │  [🔲 Крышки]           │
   │  [🔋 Аккумуляторы]     │
   │  [📞 Шлейфы iPhone]    │
   │  [🤖 Шлейфы Android]   │
   │  [📷 Камеры]           │
   │  [🔊 Динамики]         │
   └────────┬───────────────┘
            │
   callback: stockin_{category}
            │
            ▼
   ┌────────────────────────┐
   │  STATE: Выбор запчасти │
   │  Загрузка из БД:       │
   │                        │
   │  SELECT * FROM parts   │
   │  WHERE category = ?    │
   │                        │
   │  [Товар 1 (qty=5)]     │
   │  [Товар 2 (qty=8)]     │
   │  [Товар 3 (qty=3)]     │
   └────────┬───────────────┘
            │
   callback: part_{part_id}
            │
            ▼
   ┌────────────────────────────────────┐
   │  STATE: StockInState.quantity      │
   │  Ввод количества                   │
   │                                    │
   │  📦 Запчасть: Дисплей iPhone 13   │
   │                                    │
   │  Введите количество:               │
   │  [Пользователь вводит число]       │
   └────────┬─────────────────────────┘
            │
   Validation: int > 0
            │ ✓
            ▼
   ┌────────────────────────────────────┐
   │  STATE: StockInState.supplier      │
   │  Ввод поставщика                   │
   │                                    │
   │  👤 Введите поставщика:            │
   │  [Пользователь вводит текст]       │
   └────────┬─────────────────────────┘
            │
            ▼
   ┌────────────────────────────────────┐
   │  STATE: StockInState.notes         │
   │  Выбор: Завершить или примечание?  │
   │                                    │
   │  [✅ Завершить]                    │
   │  [📝 Добавить примечание]          │
   └────────┬─────────────────────────┘
            │
            ├──────────────┬──────────────┐
            │              │              │
      [✅ Завершить]  [📝 Примечание]
            │              │
            │              ▼
            │        ┌──────────────┐
            │        │ Ввод текста  │
            │        │ примечания    │
            │        └──────┬───────┘
            │               │
            │               └──────────────┐
            │                              │
            ▼                              ▼
   ┌──────────────────────────────────────────┐
   │  ФИНАЛИЗАЦИЯ                             │
   │                                          │
   │  1. UPDATE parts                         │
   │     SET quantity = quantity + N          │
   │     WHERE id = part_id                   │
   │                                          │
   │  2. INSERT stock_history                 │
   │     (part_id, quantity, supplier, notes) │
   │                                          │
   │  3. Отправить подтверждение              │
   └──────────────┬───────────────────────────┘
                  │
                  ▼
   ┌──────────────────────────────────────┐
   │  ✅ Приходование завершено!          │
   │                                      │
   │  📦 Запчасть: Дисплей iPhone 13    │
   │  📊 Кол-во: +15 шт                   │
   │  👤 Поставщик: AliExpress            │
   │  📝 Примечание: (если было введено)   │
   │                                      │
   │  [📦 Каталог] [📥 Приходование]    │
   │  [⚙️  Админ-панель]                   │
   └──────────────────────────────────────┘
```

```

└────────┬─────────┘
         │
  IF user_id == ADMIN_ID
         │ ✓
         ▼
    ┌─────────────────┐
    │  Админ-меню     │
    │                 │
    │  ➕ Добавить    │
    │  📊 Статистика  │
    │  🔙 Назад       │
    └────────┬────────┘
             │
    Выбор: ➕ Добавить
             │
             ▼
    ┌────────────────────────────┐
    │  STATE: PartState.category │
    │  Выбор категории           │
    │                            │
    │  [📱 Дисплеи]              │
    │  [🔲 Крышки]               │
    │  [🔋 Аккумуляторы]         │
    │  [📞 Шлейфы iPhone]        │
    │  [🤖 Шлейфы Android]       │
    │  [📷 Камеры]               │
    │  [🔊 Динамики]             │
    └────────┬─────────────────┘
             │
    callback: addcat_{category}
             │
             ▼
    ┌────────────────────────────┐
    │  STATE: PartState.name     │
    │  Введите название          │
    │  [Админ вводит текст]      │
    └────────┬─────────────────┘
             │
             ▼
    ┌────────────────────────────┐
    │  STATE: PartState.supplier │
    │  Введите поставщика        │
    │  [Админ вводит текст]      │
    └────────┬─────────────────┘
             │
             ▼
    ┌────────────────────────────────┐
    │  STATE: PartState.cost_price   │
    │  Введите себестоимость         │
    │  [Админ вводит число]          │
    │                                │
    │  Validation: float > 0         │
    └────────┬──────────────────────┘
             │
             ▼
    ┌────────────────────────────────────┐
    │  STATE: PartState.retail_price     │
    │  Введите розничную цену            │
    │  [Админ вводит число]              │
    │                                    │
    │  Validation: float > retail_cost   │
    └────────┬──────────────────────────┘
             │
             ▼
    ┌────────────────────────────────────┐
    │  STATE: PartState.wholesale_price  │
    │  Введите оптовую цену              │
    │  [Админ вводит число]              │
    │                                    │
    │  Validation: float > 0             │
    └────────┬──────────────────────────┘
             │
             ▼
    ┌────────────────────────────────────┐
    │  ФИНАЛИЗАЦИЯ                       │
    │                                    │
    │  INSERT INTO parts                 │
    │  (category, name, supplier,        │
    │   cost_price, retail_price,        │
    │   wholesale_price, quantity=0)     │
    │                                    │
    │  State.clear()                     │
    └────────┬──────────────────────────┘
             │
             ▼
    ┌───────────────────────────┐
    │  ✅ Запчасть добавлена!   │
    │                           │
    │  Категория: ...           │
    │  Название: ...            │
    │  Поставщик: ...           │
    │                           │
    │  [➕ Добавить]             │
    │  [📊 Статистика]          │
    │  [🔙 Назад]               │
    └───────────────────────────┘
```

## 🔄 FSM State Transitions (Приходование)

```
                    START
                      │
                      ▼
        ┌─────────────────────────┐
        │  Выбор категории        │
        │  (callback: stockin_)    │
        └────────────┬────────────┘
                     │
                     ▼
        ┌─────────────────────────┐
        │  Выбор запчасти         │
        │  (callback: part_)      │
        │                         │
        │  SET: part_id           │
        │  SET: part_name         │
        └────────────┬────────────┘
                     │
                     ▼
        ┌─────────────────────────┐
        │  QUANTITY               │
        │                         │
        │  Ввод: целое число > 0  │
        │  SET: quantity          │
        └────────────┬────────────┘
                     │
                     ▼
        ┌─────────────────────────┐
        │  SUPPLIER               │
        │                         │
        │  Ввод: текст            │
        │  SET: supplier          │
        └────────────┬────────────┘
                     │
                     ▼
        ┌──────────────────────────────┐
        │  NOTES                       │
        │                              │
        │  Выбор:                      │
        │  ├─ [✅ Завершить]           │
        │  │   → UPDATE БД             │
        │  │   → INSERT history        │
        │  │   → CLEAR state           │
        │  │   → END ✅                │
        │  │                           │
        │  └─ [📝 Примечание]          │
        │      → Повтор ввода         │
        │      → Возврат на NOTES     │
        └──────────────────────────────┘
```

## 🎯 Decision Trees

### Дерево решений: Приходование

```
НАЧАЛО
  │
  ├─ Категория существует?
  │  ├─ ДА → Загрузить запчасти
  │  │       │
  │  │       ├─ Запчасти есть?
  │  │       │  ├─ ДА → Выбрать запчасть
  │  │       │  │       │
  │  │       │  │       ├─ Ввести количество > 0?
  │  │       │  │       │  ├─ ДА → Ввести поставщика
  │  │       │  │       │  │       │
  │  │       │  │       │  │       ├─ Добавить примечание?
  │  │       │  │       │  │       │  ├─ ДА → Ввести примечание
  │  │       │  │       │  │       │  │       └─ Завершить
  │  │       │  │       │  │       │  │
  │  │       │  │       │  │       │  └─ НЕТ → Завершить
  │  │       │  │       │  │       │           │
  │  │       │  │       │  │       │           ▼
  │  │       │  │       │  │       │       UPDATE + INSERT
  │  │       │  │       │  │       │       │
  │  │       │  │       │  │       │       ▼
  │  │       │  │       │  │       │       УСПЕХ ✅
  │  │       │  │       │  │
  │  │       │  │       │  └─ НЕТ → Ошибка ❌
  │  │       │  │       │           Повторить
  │  │       │  │
  │  │       │  └─ НЕТ → Ошибка ❌
  │  │       │           Добавить через админ
  │  │
  │  └─ НЕТ → Ошибка ❌
  │           Выбрать существующую
  │
  └─ КОНЕЦ
```

## ⚡ Performance Flow

```
ПОЛЬЗОВАТЕЛЬ НАЖИМАЕТ КНОПКУ
        │
        ▼
DISPATCHER ПОЛУЧАЕТ CALLBACK
        │
        ▼
ПРОВЕРКА ПРАВ (если необходимо)
        │
        ├─ Ошибка? → Отправить сообщение об ошибке
        │
        ▼
ПОЛУЧИТЬ ДАННЫЕ ИЗ БД
        │
        ├─ SELECT (максимум 10-20 строк)
        │
        ▼
ОБРАБОТАТЬ В ПАМЯТИ (< 1ms)
        │
        ├─ Форматирование
        ├─ Определение цены
        ├─ Создание клавиатуры
        │
        ▼
ОТПРАВИТЬ В TELEGRAM
        │
        ▼
ПОЛУЧИТЬ ОТВЕТ ОТ ПОЛЬЗОВАТЕЛЯ
        │
        ▼
ОБНОВИТЬ STATE или БД
        │
        ▼
ОТПРАВИТЬ ПОДТВЕРЖДЕНИЕ
        │
        ▼
ЗАВЕРШИТЬ
```
