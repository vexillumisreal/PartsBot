## 🏛️ Ключевые модули

### 1. Ядро приложения (`bot.py`, `config.py`)
- **Инициализация**: Aiogram `Dispatcher` с `MemoryStorage`.
- **Подключение роутеров**:
  1. `common.router` — команды `/start`, `/help`, ролевые меню.
  2. `catalog.router` — 4-уровневый каталог, поиск, карточки товаров, генерация QR.
  3. `orders.router` — корзина, шаги оформления заказа, нотификация менеджеров.
  4. `stock.router` — складские операции (приход с фиксацией закупочной стоимости, списание, инвентаризация).
  5. `admin.router` — управление заказами клиентов, прогноз закупок (Smart Procurement), аналитика KPI, выгрузка CSV.
  6. `roles.router` — назначение прав доступа, рассмотрение заявок на опт.

### 2. Уровень базы данных (`db.py`)
- Полностью асинхронный доступ через `aiosqlite`.
- Автоматические миграции колонок `part_type` в `parts` и `price` в `stock_history`.
- Индексы быстродействия для поиска по номенклатуре и иерархии:
  ```sql
  CREATE INDEX IF NOT EXISTS idx_parts_hierarchy ON parts(category, subcategory, part_type);
  CREATE INDEX IF NOT EXISTS idx_parts_name ON parts(name);
  ```

### 3. Парсер прайс-листов (`import_kazan_prices.py`)
- Загрузка данных из Excel (`openpyxl`).
- Интеллектуальный классификатор моделей и типов деталей.
- Фиксация розничной цены из колонки F и автоматический расчет оптовой цены (-20%).

## 🔐 Безопасность и права доступа
- Административные функции защищены списком `ADMIN_IDS` в `config.py` и таблицей `users.role`.
- Проверка прав выполняется на уровне каждого обработчика через `db.is_admin(user_id)` и `db.get_user_role(user_id)`.
